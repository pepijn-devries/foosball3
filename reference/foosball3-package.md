# foosball3: An App to Manage and Organise Foosball Tournaments

A relational SQLite database used to manage leisure foosball
tournaments. This package provides a features and a graphical user
interface to easily access the database. It also allows to visualise
(historical) data and account player history. It can be used to
facilitate a live tournament.
